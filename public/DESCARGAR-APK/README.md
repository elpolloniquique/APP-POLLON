# Carpeta de descarga APK — El Pollón Repartidor

Después de `npm run build:apk:debug` + `npm run copy:apk`, aquí queda:

`El-Pollon-repartidor.apk`

URL en producción (cuando el archivo esté alojado en el hosting / CDN):

`https://www.el-pollon.cl/DESCARGAR-APK/El-Pollon-repartidor.apk`

> El APK (~180–200 MB) **no se sube a GitHub** (límite 100 MB).
> Súbelo a Supabase Storage, Vercel Blob o tu CDN y apunta la misma ruta, o sírvelo desde este `public/` en el host que acepte archivos grandes.

Ver `docs/DRIVER_NATIVE_ANDROID.md`.
